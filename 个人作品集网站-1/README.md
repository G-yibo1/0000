# 个人作品集网站

欢迎来到我的个人作品集网站！这个网站展示了我的设计与开发项目，旨在展示我的技能和经验。以下是项目的概述和设置说明。

## 项目概述

这个个人作品集网站包含以下几个主要部分：

- **首页**：介绍我自己和我的工作理念。
- **作品展示**：展示我参与的项目，包括每个项目的描述、技术栈以及相关的静态和动态图片。
- **经历**：列出我的教育背景和工作经历。
- **联系我**：提供联系方式，方便潜在的雇主或合作伙伴与我联系。

## 文件结构

- `index.html`：主HTML文档，包含网站的结构和内容。
- `assets/pdf`：存放与项目相关的PDF文件，用户可以下载查看。
- `assets/projects`：存放项目相关的图片和媒体文件，包括静态图像和动态内容。

## 设置说明

1. **克隆或下载项目**：
   - 使用Git克隆此项目：
     ```
     git clone <repository-url>
     ```
   - 或者直接下载ZIP文件并解压。

2. **打开项目**：
   - 使用浏览器打开 `index.html` 文件以查看个人作品集。

3. **添加项目内容**：
   - 在 `assets/pdf` 文件夹中添加相关的PDF文件。
   - 在 `assets/projects` 文件夹中添加项目的静态和动态图片。
   - 更新 `index.html` 文件以包含新项目的内容和链接。
