# Personal Portfolio

This project is a personal portfolio website that showcases my work, skills, and experiences. It is designed to provide a comprehensive overview of my professional background and projects.

## Project Structure

The project is organized as follows:

```
personal-portfolio
├── src
│   ├── index.html          # Main HTML file that loads other components and resources
│   ├── styles
│   │   └── main.css       # Main stylesheet defining the layout, colors, and fonts
│   ├── scripts
│   │   └── main.js        # Main JavaScript file for handling interactions and dynamic content
│   ├── components
│   │   ├── header.html     # Header component with navigation and title
│   │   ├── about.html      # About me component with personal background information
│   │   ├── resume.html     # Resume component showcasing education and work experience
│   │   ├── projects.html    # Projects component displaying my project experience
│   │   ├── skills.html     # Skills component listing my technical skills
│   │   └── contact.html    # Contact component with contact information and social links
│   └── data
│       └── profile.json    # JSON file containing personal information for other components
├── package.json            # npm configuration file listing dependencies and scripts
└── README.md               # Documentation file with project description and usage instructions
```

## Installation

To get started with this project, clone the repository and install the necessary dependencies:

```bash
git clone <repository-url>
cd personal-portfolio
npm install
```

## Usage

To run the project, you can open the `index.html` file in your web browser. For a better development experience, consider using a local server.

## Features

- Responsive design
- Interactive components
- Easy navigation
- Showcase of skills and projects
